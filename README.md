# t3-plugins

Plugins for the [plugin build of T3 Code](https://github.com/marcelocantos/t3code), the fork that
adds sidebar panels, link cards and link activation. Each directory is one self-contained plugin.

| Plugin | What it does |
|---|---|
| [open-with](open-with/) | A plain click on a Markdown file link opens the file with the application your machine registers for it, such as Vellum Viewer. |

Each plugin's README says how to build it and register it with T3. The protocol itself is
specified in [panel plugins](https://github.com/marcelocantos/t3code/blob/main/docs/operations/panel-plugins.md).
Writing a new plugin: see [docs/authoring.md](docs/authoring.md).
